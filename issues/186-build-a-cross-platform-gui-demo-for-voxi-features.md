# 186 — Build a cross-platform GUI demo for voxi features

**Status**: Open
**Priority**: P2 (Medium)
**Severity**: Moderate
**Category**: Feature
**Related**:

---

## 1. Problem & Motivation
Voxi's Go code, models, and logic need an approachable cross-platform GUI for demonstrating and exercising the project's features.

**Goal**: Build a cross-platform demo GUI that runs voxi's Go code and provides a way to expose and test its features. Stop and report if a platform, feature, or safety constraint requires a user decision or permission.

## 2. Technical Specification / Findings
The supported platform matrix, GUI toolkit, and feature-by-feature test/demo scope remain to be determined against the current project architecture.

## 3. Implementation & Verification Plan
Survey current voxi features and platform constraints; implement the GUI and feature workflows; verify builds and relevant behavior on supported platforms, documenting any features that cannot be safely or meaningfully exercised through the GUI.
