# Tested Models Catalog

Consolidated reference of all Automatic Speech Recognition (ASR) and Text-to-Speech (TTS) models evaluated, benchmarked, prototyped, or integrated in Voxi.

This document serves as the project memory for model performance, runtime architecture requirements, license constraints, and benchmark verdicts across standard development hardware.

---

## 1. Standard Hardware Testbeds

Benchmark measurements cited in this catalog are recorded against the following standardized machine profiles:

- **Primary Laptop (`t14`)**:
  - **Machine**: Lenovo ThinkPad T14 Gen2 AMD
  - **CPU**: AMD Ryzen 5 PRO 5650U (6 cores / 12 threads)
  - **GPU / VRAM**: AMD Radeon Graphics (Cezanne / RADV RENOIR, Vulkan 1.4, `/dev/dri/renderD128`, shared system memory)
  - **RAM**: 24 GB DDR4
  - **OS**: Fedora Linux (Wayland, kernel 7.1.x)
- **Workstation Server (`x600`)**:
  - **Machine**: Minisforum / ASRock DeskMini X600
  - **CPU**: AMD Ryzen 7 8700G (8 cores / 16 threads)
  - **GPU**: Radeon 780M (RDNA3, Vulkan 1.4 / ROCm)
  - **Topology**: Upstream server host reachable over SSH tunnels via `lmcoder` proxy (port 8735).

## 4. Current Architecture Summary

### Active Models & Roles

1. **ASR Primary Daily Driver**: `r2t2-confucius4`
   - Served via `lmcoder` proxy (`http://127.0.0.1:8735/v1`) using resident `llama-server` on GPU with automatic failover to local fallback unit `voxi-r2t2.service` (`http://127.0.0.1:18131/v1`).
2. **ASR Embedded Default**: `cohere-transcribe-03-2026`
   - Managed via `crispasr` (GGUF `q5_0`) with zero external service dependencies.
3. **ASR Lightweight Fallbacks**: `whisper` (`base.en` on GPU, `small.en` on CPU).
4. **TTS Standard Desktop Narrator**: `piper` (`en_US-lessac-medium.onnx`).
5. **TTS Cloned Voice Backend**: `voxcpm` (`voxcpm-0.5b-q8_0-audiovae-f16.gguf` via Vulkan `audiocpp_cli`).
