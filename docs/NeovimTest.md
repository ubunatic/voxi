# Voxi Test in Neovim

1. Open `voxi monitor -w` in another terminal to see voxi status and CPU/GPU load.
2. Position cursor on next line and press `Super-X` and start dictating.
3. Press Enter for line breaks, pause speaking to make edits manually. Have fun!
