VOXIvoxi 0.1.13

voxi

Standalone Linux voice input, continuous eager streaming, and desktop typing engine

Voxi is a high-performance voice input and typing engine for Linux/Wayland.
It provides continuous eager sentence streaming with local Cohere Transcribe by default,
modifier key gating daemon for hotkey safety, synthetic typing injection, and a btop-style monitor.

VOXI-BENCHvoxi 0.1.13

voxi bench [flags]

Benchmark CPU vs GPU transcription speed across configured Whisper models

Transcribes one audio clip through every whisper-engine model in spec/models.yaml
(driven via voxtype) on each requested backend, reporting the real-time factor (RTF)
and speedup for each model x backend pair. Non-whisper engines (e.g. cohere-transcribe)
are reported as skipped rather than benched. By default it uses a fixed reference clip
downloaded on demand into the user cache dir (never committed to the repo); pass
--record for a live microphone clip or --file for a local WAV.

--backends
comma-separated backends to bench: cpu, gpu (default: gpu,cpu) (default: [gpu,cpu])
--duration
seconds of microphone audio to record when --record is set (default: 8)
--file
use this 16kHz mono WAV instead of the reference clip or recording
--json
write the full bench report as JSON to this path
--models
comma-separated model names to bench (default: every whisper-engine model in spec/models.yaml; non-whisper models are reported as skipped)
--record
record live microphone audio instead of using the downloaded reference clip
--threads
CPU threads passed to voxtype (default: 6)

VOXI-COMPLETION-BASHvoxi 0.1.13

voxi completion bash

Generate the autocompletion script for bash

Generate the autocompletion script for the bash shell.

This script depends on the 'bash-completion' package.
If it is not installed already, you can install it via your OS's package manager.

To load completions in your current shell session:

source <(voxi completion bash)

To load completions for every new session, execute once:

#### Linux:

voxi completion bash > /etc/bash_completion.d/voxi

#### macOS:

voxi completion bash > $(brew --prefix)/etc/bash_completion.d/voxi

You will need to start a new shell for this setup to take effect.

--no-descriptions
disable completion descriptions

VOXI-CONFIG-IMPORTvoxi 0.1.13

voxi config import DIR [flags]

Merge stop-words, replacements, and vocabulary from another machine's local Voxi state

Merge stop-words.json, replacements.json, and vocabulary.txt from DIR --
a local, previously-copied ~/.config/voxi-shaped directory -- into this machine's
local Voxi state. DIR must already be a local directory (e.g. copied over with
scp/rsync/USB beforehand) -- import performs no transfer of its own.

config.yaml and env are intentionally not imported: they hold machine-specific
settings (paths, device IDs) that don't safely carry over between machines.

--only
import only these areas: stop-words,replacements,vocabulary (default: all found in DIR)
--overwrite
replace a colliding replacement entry instead of skipping it (stop-words and vocabulary are always additive)

VOXI-DAEMON-MODIFIER-SERVICEvoxi 0.1.13

voxi daemon modifier-service [flags]

Dedicated evdev modifier key state monitoring daemon

Monitors physical modifier keys (Ctrl, Alt, Super, Shift) across all /dev/input/event* keyboards,
and exports an atomic 1-byte bitmask state to a world-readable file (/run/voxi/modifiers).
Never captures or records non-modifier keycodes, preserving strict privacy.

--interval
polling and update interval (default: 10ms) (default: 10ms)
--state-file
path to world-readable modifier state file (default: /run/voxi/modifiers) (default: /run/voxi/modifiers)
VOXI-EAGERvoxi 0.1.13

voxi eager [flags]

Continuous eager sentence streaming dictation into focused window

Continuously captures audio from the microphone with a circular pre-roll buffer.
Segments speech on natural conversational pauses (silence > 800ms) or rolling windows,
transcribes completed phrases immediately with the selected model's engine (Cohere
Transcribe via crispasr by default, or Whisper via voxtype for an explicit --model),
and types finalized sentences directly into the active application via dotool with zero
dropped words across pauses. crispasr is required for the default engine; voxtype is only
required when an explicit Whisper --model is selected.

--daemon
run as background systemd daemon listening for toggle control
--history
record transcribed utterances into local dictation history (default: true)
--max-window
maximum window length in ms before forcing a phrase chunk (default: 8000) (default: 8000)
--min-speech
minimum speech duration in ms to ignore noise (default: 200) (default: 200)
--model
model name, see spec/models.yaml (default: cohere-transcribe-03-2026)
--modifier-gating
wait for physical modifiers before typing output (default: true)
--pre-roll
pre-speech circular buffer duration in ms to preserve starting phonemes (default: 500) (default: 500)
--silence
silence duration in ms to finalize an utterance chunk (default: 800) (default: 800)
--speech-context
bounded local vocabulary hints (default: true)
--threshold
audio RMS energy threshold to trigger speech detection (default: 150) (default: 150)
--type
type transcribed sentences directly into the focused window via dotool (default: true)
--vocabulary
additional comma-separated speech-context terms

VOXI-INSTALLvoxi 0.1.13

voxi install [flags]

Install Voxi for this user (optional: --modifierd needs sudo)

Install the CLI and systemd user services under your home directory, then enable and start voxi-agent.service.
When TTS tools are missing, Voxi asks before using sudo and the system package manager.

Use --no-tts to persistently opt out of TTS packages. Use --voxcpm to install the VoxCPM Vulkan runtime and cloned-voice model. Use --modifierd for the optional system-wide physical modifier daemon; it also requires sudo and Linux systemd.

--modifierd
also install the optional system-wide modifier daemon (requires sudo)
--no-tts
disable TTS and skip Festival/espeak-ng system packages
--voxcpm
install the VoxCPM Vulkan runtime, model, and cloned-voice references
VOXI-MANvoxi 0.1.13

voxi man [flags]

generate and print or install roff man pages

man generates standard roff/troff man pages from voxi's command tree.

Without flags, it prints the roff man page to stdout (e.g. voxi man | man -l -).
With --install, it writes .1 man pages to ~/.local/share/man/man1
(or /usr/local/share/man/man1 if root).
With --html, it prints one static HTML page covering every command to stdout.

-d, --dir
custom target directory for man pages (implies --install)
-h, --help
help for man
--html
print one static HTML page covering every command to stdout
--install
install man pages into standard system or user man directory

VOXI-SAMPLE-MERGEvoxi 0.1.13

voxi sample merge ID SOURCE... [flags]

Merge samples or chunks into one longer sample

Join two or more samples (or, with --chunks, recent chunks) in the given order into a new sample.
Parts are separated by --gap silence and must share sample rate and format; nothing is resampled or normalized.
The joined transcript opens in $VISUAL/$EDITOR for review. Inputs are never changed; the new sample's
source field lists them. Chunks must come from one session, be accepted, and lie at most 30s apart,
unless --force is given.

Example: voxi sample merge paragraph intro-1 intro-2
Example: voxi sample merge paragraph --chunks 12 13 14 --purpose voice

--chunks
sources are chunk indices from `voxi chunks list`
--force
allow chunks from different sessions, far apart, or rejected
--gap
silence between parts (default: 300ms)
--max-duration
refuse merged audio longer than this (default: 20s)
--own-voice
confirm without prompting that this is your own voice and you consent to cloning it
--purpose
purpose of the new sample (default: the sources' purpose, dictation for chunks)

VOXI-VOICEvoxi 0.1.13

voxi voice

Prepare and train custom Piper voices

Build TTS voices from your voice-purpose samples. Only samples in the voice purpose, stored with your own-voice consent, are ever read.

Terms:
chunk one recording cut by live dictation, with its ASR diagnostics; only the
last 100 are kept, in $XDG_RUNTIME_DIR (cleared on reboot) when available
sample a saved recording with its exact transcript, stored by purpose under
~/.local/share/voxi/samples/{dictation,noise,voice}
purpose dictation (ASR accuracy checks), noise (must yield no text; the only
publishable purpose) or voice (your own voice, for cloning and training;
needs your consent)
publish copy a noise sample into the repository's public store (testdata/samples)
merge join samples or chunks into one longer sample
voice an installed TTS voice, built from voice samples; not a sample itself
Reference: docs/SampleStore.md

VOXI-VOICE-CLONEvoxi 0.1.13

voxi voice clone [flags]

Install a voice sample as a cloned-voice profile

Copies one voice-purpose sample WAV from the private sample store to ~/.local/share/voxi/voices/<name>.wav and records it as tts_voice_reference_wav in ~/.config/voxi/config.yaml for a cloned-voice engine. Only clone your own voice.

--name
voice profile name used for the installed WAV (default: cloned)
--sample
voice sample id to clone (required when more than one voice sample exists)
--store
private sample store root; only voice-purpose samples are used (default: /home/uwe/.local/share/voxi/samples)

VOXI-VOICE-TRAINvoxi 0.1.13

voxi voice train [flags]

Fine-tune and install a custom Piper voice

Prepare voice-purpose samples from the private sample store, fine-tune a Piper medium checkpoint, export ONNX, and install the voice under ~/.local/share/voxi/voices/.

--accelerator
training accelerator: cpu or gpu (default: cpu)
--base
local medium checkpoint path or checkpoint URL (default: https://huggingface.co/datasets/rhasspy/piper-checkpoints/resolve/main/en/en_US/lessac/medium/epoch%3D2164-step%3D1355540.ckpt)
--batch-size
Piper training batch size (default: 16)
--dataset-dir
prepared LJSpeech dataset directory (default: /home/uwe/.local/share/voxi/voice-training/dataset)
--epochs
training epoch limit (default: 100)
--espeak-voice
espeak-ng language voice, for example en-us (default: en-us)
--name
voice name used for the installed ONNX files
--store
private sample store root; only voice-purpose samples are used (default: /home/uwe/.local/share/voxi/samples)
--work-dir
training logs, checkpoints, and exported model directory (default: /home/uwe/.local/share/voxi/voice-training/runs)
