Rolling Whisper inference segments speech on natural pauses with zero dropped words and sub-250ms latency.

🔒 Modifier Gating Daemon

The voxi-modifierd daemon watches evdev physical modifier state, guaranteeing hotkey safety with zero keylogging.

📊 Btop-Style Resource Monitor

Live terminal dashboard tracks transcription latency, audio level meters, CPU load, and AMD GPU Vulkan acceleration.

Quick Start

# Install voxi and modifier daemon
go install ubunatic.com/voxi/cmd/voxi@latest
go install ubunatic.com/voxi/cmd/voxi-modifierd@latest

# Run continuous eager sentence dictation
voxi eager

# Live resource monitor
voxi monitor --watch
