voxi types what you say, as you say it.

High-quality, local speech-to-text dictation for Linux/Wayland, now using Cohere Transcribe 03-2026 by default for strong local recognition. Voxi currently runs the default path with English forced; multilingual model support is not yet exposed as a user language setting. Continuous eager sentence streaming, kernel-level modifier key gating safety, and direct synthetic typing injection into any active window. Audio stays on your machine; after a one-time model download, transcription works offline on the CPU.

How it works

  1. Listens continuously with a circular pre-roll buffer (500ms default), so the first phonemes of a sentence are never clipped.
  2. Segments speech automatically on natural pauses (800ms default) and transcribes each phrase eagerly, in sub-second bursts.
  3. Gates on physical modifier keys — while Super, Ctrl, Alt, or Shift is held down, typed output is buffered, then flushed the instant it's released, so dictation never collides with a hotkey.
  4. Transcribes locally with Cohere Transcribe running on the CPU (no audio leaves the machine), and types directly into the active window via dotool.
  5. Optionally logs history — with --history, each finalized utterance is appended to a local dictation log for later reuse.
voxi eager --type --history

Engine Highlights & Architecture

Engineered for seamless voice dictation without lag, dropped words, or accidental hotkey triggers.

⚡

Continuous Eager Streaming

Maintains a circular pre-roll buffer to preserve initial phonemes. Utterances are segmented on natural pauses (800ms silence) or rolling windows and transcribed eagerly in sub-second bursts with zero dropped words across pauses.

voxi eager / voxi agent
🛡️

Physical Modifier Gating Safety

Monitors physical modifier keys (Ctrl, Alt, Super, Shift) directly from the kernel via evdev EVIOCGKEY with sub-10ns release gating. Prevents destructive hotkey collisions while strictly guaranteeing zero non-modifier keylogging.

voxi-modifierd
⌨️

Direct Synthetic Keystrokes

Types directly into active Wayland windows using dotool/dotoold with full XKB layout awareness (e.g. German QWERTZ, Colemak, Dvorak) and instantaneous atomic clipboard fallback (wl-copy).

dotool + wl-copy
📊

Btop-Style Resource Monitor

A rich terminal HUD displaying real-time audio RMS energy meters, transcription latency sparklines, GPU Vulkan / CPU utilization, and daemon health stats with interactive panel controls.

voxi monitor --watch

Spec-Driven Hallucination Filtering

Automatically suppresses known silence hallucinations and repetitive subtitle loops using embedded, per-model specifications (spec/models.yaml). Whisper alternatives retain their own backend and GPU fallback behavior.

Chunk Diagnostics

A bounded ring buffer of the most recently recorded audio segments, so you can see exactly why a chunk was accepted or rejected without re-recording.

voxi chunks list

Each row carries the acoustic-gate evidence behind its outcome: RTF (real-time factor) and mean RMS energy, plus a Braille LEVEL sparkline showing where in the segment the energy actually was — a brief loud syllable in otherwise silence looks very different from uniformly moderate speech, even with the same mean RMS. Rejected chunks are labeled with the specific gate that caught them (low_energy_transient, unvoiced_transient, stop_word). voxi chunks show <index> prints one chunk's full detail; voxi chunks play <index> replays its captured audio.

Spec-Driven Architecture

Spec files are the single source of truth — application code must not duplicate or shadow spec values. Every YAML file is embedded directly into the binary and validated against a companion JSON Schema. 

spec/
├── actions.yaml  # voxi monitor hotkeys & display labels
├── models.yaml   # ASR model registry & hallucination filters
├── monitor.yaml  # redraw rate & live mic-level ballistics
└── schemas
    ├── actions.schema.json
    ├── models.schema.json
    └── monitor.schema.json

spec/models.yaml names every ASR model voxi can drive and its per-model hallucination stop-words. spec/actions.yaml is the single source for voxi monitor's hotkeys — box titles and footer badges resolve their key letters from it, so they can never drift out of sync with the actual dispatcher. spec/monitor.yaml tunes the live mic-loudness meter (paint FPS, capture rate, attack/decay ballistics) without touching Go code.

Why Cohere Transcribe?

Voxi adopted Cohere Transcribe 03-2026 after local canary testing showed a clear recognition-quality improvement on its English dictation fixtures, including technical terms and embedded German words. The default stays private in use: crispasr performs inference locally on the CPU and sends no audio to a transcription service.

Quickstart & Installation

Get up and dictating in under two minutes.

1

Install Voxi

Use the official one-line installer to configure the binary, dependencies (crispasr, dotoold), and systemd user services: 

$ curl -fsSL https://codeberg.org/ubunatic/voxi/raw/branch/main/scripts/install.sh | bash
# (Optional) Include privileged physical modifier gating setup
$ curl -fsSL https://codeberg.org/ubunatic/voxi/raw/branch/main/scripts/install.sh | bash -s -- --modifierd

Or install from source with Go, then run the same user setup: 

$ git clone https://codeberg.org/ubunatic/voxi.git && cd voxi
$ go install ./cmd/voxi
$ ~/go/bin/voxi install              # User setup; make install does both steps
$ ~/go/bin/voxi install --modifierd  # Optional system daemon (needs sudo)
2

Verify Background Agent

Ensure the background voice service is active:

$ systemctl --user is-active voxi-agent.service
3

Start Dictating

Toggle recording from the CLI or a desktop hotkey:

$ voxi record toggle    # Toggle dictation recording
$ voxi record status    # Check current state
$ voxi monitor --watch  # Open live btop dashboard

voxi record toggle is a plain CLI command — bind it to any key combination you want, on any desktop that supports custom shortcuts. voxi shortcut setup automates this for GNOME's standard Super+X, but you can wire up your own binding directly in your desktop's keyboard settings, pointing it at the full path to the voxi binary:

First-run model download

The default backend lazily downloads the approximately 1.66 GiB Q5_0 GGUF from the ungated cstr/cohere-transcribe-03-2026-GGUF community mirror into ~/.cache/voxi/models/. This first uncached run needs network access; subsequent transcription uses the cached weights locally and works offline. Your audio is never uploaded for transcription.

Commands

install [--modifierd]
Configure user binaries, dependency runtime tools (crispasr, dotool, dotoold), and systemd user services. With --modifierd, also builds and installs the privileged kernel evdev modifier daemon.
mode [batch|streaming|eager]
Show the active voice-input mode, or switch to one of the three transcription strategies. With no argument, prints the current mode.
record {toggle|start|stop|status}
Control an active dictation recording session out-of-band, e.g. from a desktop hotkey.
eager [flags]
Run continuous eager sentence streaming dictation. Segments speech on pauses and transcribes phrases in real-time.
monitor [-w|--watch] [-i seconds] [-s sections]
Print or live-refresh a btop-style report covering transcription latency, audio RMS meters, CPU/GPU loads, and daemon health. Aliases: top, stats, resources.
chunks {list|show|play} [INDEX|last]
Inspect the ring buffer of recently recorded audio chunks and their acoustic-gate outcome. list shows a colorized RMS/LEVEL sparkline table; show prints one chunk's full detail; play replays its captured audio.
bench [flags]
Benchmark transcription speed (RTF & speedup) for models declared in spec/models.yaml across cpu and gpu backends against standard reference samples.
history {list|clear|copy ID|retype ID}
Inspect and reuse local dictation transcripts. copy places text onto the clipboard; retype injects it directly into the active window.
shortcut {setup|remove}
Configure or remove the standard Super+X recording-toggle shortcut on GNOME. setup checks for conflicts before installing; other desktop environments are not yet supported.
feedback {stop-word|silence-artifact|vocabulary|replacement} {add|remove|list}
Manage local corrections layered on top of the shipped model defaults, never sent anywhere. replacement maps an exact heard-form to a written-form (e.g. a misheard project name); stop-word and silence-artifact add phrases to discard as hallucinated filler or whole-utterance noise; vocabulary adds persistent Whisper decoder-context terms (the default Cohere backend does not use decoder vocabulary prompting). voxi feedback status summarizes all active local overrides. Real examples from this project's own dictation (voxi feedback replacement add HEARD WRITTEN): codeblock, codebroad, codebrook, codeburg, and coldburg → codeberg; wipe-coded → vibe-coded; harness project → harnez project.
config {get|set} type-delay-ms [MS]
Read or change typing speed in voxtype configuration to adjust keystroke pacing for legacy or latency-sensitive applications.
daemon modifier-service [flags]
Run the evdev modifier monitoring service directly (normally managed via voxi-modifierd system service).

Eager Options

--threshold N
Audio RMS energy threshold to trigger speech detection (default: 150).
--silence ms
Silence pause duration required to finalize a phrase utterance chunk (default: 800ms).
--pre-roll ms
Pre-speech circular buffer duration, preserving initial phonemes from clipping (default: 500ms).
--min-speech ms
Minimum speech duration to accept as a valid utterance rather than discarding as background noise (default: 200ms).
--max-window ms
Maximum window length before forcing transcription chunking even without a natural pause (default: 8000ms).
--type
Directly inject transcribed sentences into the active window via dotool(1).
--history
Log transcribed utterances into the local dictation history store.
--daemon
Run as a background daemon responding to record toggle controls.
--model name
ASR model to load. The default is cohere-transcribe-03-2026, running locally on the CPU through crispasr. Select base.en, small.en, or large-v3-turbo to use an optional Whisper backend.

Modifier Gating Architecture

voxi-modifierd reads physical modifier key states directly from the Linux kernel via evdev's EVIOCGKEY, completely independent of compositor or window manager events. When a modifier such as Super, Ctrl, Alt, or Shift is physically depressed, voxi buffers typed output and flushes it immediately upon release (sub-10ns gating). This prevents accidental window close commands or shortcut collisions during push-to-talk dictation while strictly ensuring zero non-modifier keylogging.
